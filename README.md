Sounding Curve and 2D Geoelectric Cross-Section Project

Overview

This project demonstrates the processing, visualization, and interpretation of geophysical electrical resistivity data.

The work focuses on Vertical Electrical Sounding (VES) data and the generation of sounding curves and 2D geoelectric cross-sections for subsurface interpretation.

Project Objectives

- Process and organize VES field data
- Generate sounding curves from resistivity measurements
- Produce 2D geoelectric cross-section visualizations
- Compare and interpret subsurface resistivity variations
- Present geophysical results in a clear and reproducible format

Tools & Technologies

- Python
- NumPy
- Matplotlib
- RES1DINV
- GitHub

Project Workflow

1. Organize and prepare the acquired geophysical data
2. Process the VES measurements
3. Generate sounding curves and visualizations
4. Produce 2D geoelectric cross-sections
5. Compare subsurface resistivity patterns
6. Interpret the results and document the findings

Project Outputs

The repository contains examples of:

- VES sounding curves
- Combined VES curve visualizations
- 2D geoelectric cross-sections
- Processed geophysical results
