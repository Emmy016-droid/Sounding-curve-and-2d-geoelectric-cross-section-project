Sounding Curve and 2D Geoelectric Cross-Section Project

Overview

This project demonstrates practical work in geophysical data processing, scientific computing, visualization, and subsurface interpretation using Vertical Electrical Sounding (VES) data.

The project combines Python-based data processing and visualization with interpreted geoelectric results generated from electrical resistivity measurements.

Project Objectives

- Process and organize VES field data
- Generate VES sounding curves
- Visualize apparent resistivity variations
- Produce 2D geoelectric cross-sections
- Compare resistivity patterns between survey stations
- Support interpretation of subsurface conditions
- Present scientific results in a clear and reproducible format

Tools & Technologies

- Python
- NumPy
- Matplotlib
- SciPy
- RES1DINV
- GitHub

Project Workflow

1. Organize and prepare VES field measurements
2. Process apparent resistivity data
3. Generate individual sounding curves
4. Combine multiple VES stations for comparison
5. Interpret geoelectric layer information using inversion results
6. Generate 2D geoelectric cross-sections
7. Review and compare the resulting subsurface patterns
8. Document the processing and results

Python Processing

The repository includes Python scripts used to process and visualize the VES data.

VES Curve Processing

"VES_curve"

The script processes apparent resistivity measurements and generates a logarithmic VES sounding curve. It also supports visualization of interpreted layer resistivities, layer thicknesses, and a defined resistivity threshold.

Combined VES Processing

"combine_VES_curves"

The script combines multiple VES stations on a single logarithmic plot to support comparison of resistivity responses across survey locations.
